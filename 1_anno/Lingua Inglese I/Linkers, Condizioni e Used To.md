# Linkers, Condizioni e Used To

---

# Connettivi (Linkers)

Parole di collegamento che uniscono frasi e idee.

## Concessione e contrasto

| Linker | Significato | Esempio |
|---|---|---|
| **although / though** | sebbene | **Although** the code is old, it works. |
| **even though** | nonostante | **Even though** it was late, we kept coding. |
| **however** | tuttavia | It works. **However**, it's slow. |
| **but** | ma | It's old **but** reliable. |
| **whereas** | mentre (confronto) | She uses a Mac, **whereas** I use Linux. |
| **while** | mentre | She studies, **while** I work. |
| **nevertheless / anyway** | ciononostante | It's hard. **Nevertheless**, try again. |
| **on the other hand** | d'altra parte | It's fast. **On the other hand**, it costs a lot. |
| **in contrast** | in contrasto | **In contrast**, the new model is lighter. |

## Causa e conseguenza

| Linker | Significato | Esempio |
|---|---|---|
| **because** | perché | The server crashed **because** there was no power. |
| **since** | poiché | **Since** we are here, let's start. |
| **as** | dato che | I'll stay **as** you need help. |
| **so** | quindi | It was late, **so** we stopped. |
| **therefore** | pertanto | The disk is full; **therefore**, delete some files. |
| **because of** | a causa di | It failed **because of** a network error. |

## Aggiunta

| Linker | Significato | Esempio |
|---|---|---|
| **and** | e | He codes **and** tests. |
| **also** | inoltre | She **also** works on databases. |
| **besides** | inoltre | **Besides**, it's cheaper. |
| **moreover / furthermore** | inoltre (formale) | **Moreover**, the results were clear. |
| **as well as** | così come | Java, **as well as** Python, is taught. |
| **in addition** | in aggiunta | **In addition**, we tested the app. |

## Esempio di contrasto con *however*

> ⚠️ **Attenzione:** *however* è un **avverbio**, quindi separato da virgola e mai usato con il congiuntore *but* nella stessa frase.

| ❌ Errato | ✅ Corretto |
|---|---|
| ~~The test was hard, however it passed.~~ | The test was hard. **However**, it passed. |
| ~~The test was hard, but however it passed.~~ | The test was hard, **but** it passed. |

# Condizioni (*If*)

## First Conditional — Realtà futura

**Regola:** *If + Present Simple, will + verbo base*

> **If** we **fix** the bug, the app **will work**.
> Se sistemiamo il bug, l'app funzionerà.

### Elementi obbligatori

| Parte | Tempo | Errore tipico |
|---|---|---|
| Frase con **if** | **Present Simple** | ~~If we will fix...~~ ❌ |
| Frase principale | **will + base** | ~~the app works~~ ❌ |

> 💡 Nel **First Conditional** NON si usa *will* nella parte con *if*, perché l'evento è possibile ma non certo.

## Forma con altre espressioni condizionali

| Espressione | Significato | Struttura |
|---|---|---|
| **if** | se | If + present, will |
| **unless** | a meno che | Unless + present, will |
| **if not** | se non | If + present + not, will |
| **as long as** | finché | As long as + present, will |
| **provided (that)** | purché / a patto che | Provided + present, will |
| **providing** | purché | Providing + present, will |
| **in case** | nel caso in cui | In case + present, will |
| **otherwise** | altrimenti | will + base, otherwise ... |

---

## *Unless* = *if not*

> ⚠️ **Unless è sempre negativo.** Non aggiungere *not*.

| ❌ Errato | ✅ Corretto |
|---|---|
| ~~Unless you don't log in, you can't access.~~ | Unless you **log in**, you can't access. |

## *As long as* e *Provided*

> **As long as** the network works, we can download files.
> Purché / A patto che ci sia rete, possiamo scaricare file.
>
> **Provided** that you back up your data, you'll be safe.

# *Used To*

Le tre forme sono diverse: è la trappola più comune di questo modulo.

| Struttura | Significato | Esempio |
|---|---|---|
| **used to + verbo base** | abitudine passata **non più vera** | I **used to** hate programming. |
| **be used to + nome / -ing** | essere **abituati** a (stato) | I'm **used to** working late. |
| **get used to + nome / -ing** | **abituarsi** a (processo) | I'm **getting used to** Linux. |
| **be used to + nome** | essere usato/abituale a (passivo) | This tool **is used to** compress files. |

---

## Confronto diretto

> I **used to** smoke. → Fumavo (ma ora non più).
> I'm **used to** smoking. → Sono abituato a fumare.
> I'm **getting used to** it. → Mi sto abituando.

### Negazione e domanda

| Forma | Negazione | Domanda |
|---|---|---|
| used to | **didn't use to** | **Did** you **use to** ...? |
| be used to | **am not used to** | **Are** you **used to** ...? |
| get used to | **am getting used to** | **Are** you **getting used to** ...? |

> 💡 **Attenzione:** la forma negativa di *used to* al passato è **didn't use to** (con *use to*, non *used to*).

---

## Esercizi

| Frase | Risposta corretta |
|---|---|
| ___ the network works, we can connect. | **As long as** |
| If you ___ the file, it will run. (save) | **save** |
| Unless you ___ in, you won't see it. (log) | **log** |
| I ___ study until midnight. (passato, non più) | **used to** |
| You will lose the data ___ you make a backup. | **unless** |
