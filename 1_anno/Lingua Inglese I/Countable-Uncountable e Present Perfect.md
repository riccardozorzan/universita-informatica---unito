# Countable / Uncountable e Present Perfect

---

# Nomi Numerabili e Non Numerabili

## Countable (numerabili)

Hanno **singolare e plurale**, si contano con i numeri.

| Singolare | Plurale |
|---|---|
| file | **files** |
| computer | **computers** |
| program | **programs** |
| server | **servers** |
| bug | **bugs** |
| language | **languages** |
| database | **databases** |

- I have **three computers**.
- There are **many bugs** in this program.
- **A** file, **two** files.

---

## Uncountable (non numerabili)

Hanno **solo il singolare**, non ammettono *a/an* né numeri.

| Non numerabile | |
|---|---|
| **information** | informazione |
| **software** | software |
| **hardware** | hardware |
| **data** | dati |
| **advice** | consiglio |
| **equipment** | attrezzatura |
| **furniture** | arredamento |
| **money** | denaro |
| **news** | notizie |
| **progress** | progresso |
| **research** | ricerca |
| **traffic** | traffico |
| **luggage / baggage** | bagagli |

> ⚠️ **Attenzione:** *software, hardware, information* sono **non numerabili**, anche se parlano di cose fisiche.

---

## Come usarli

### ✅ Corretto

- I need **some information**. (some = un po' di)
- We need **much software**. / **a lot of software**
- Is there **any** progress?
- **How much** information do you have?
- There isn't **any** data.

### ❌ Errato

| Errato | Corretto |
|---|---|
| ~~an information~~ | ~~some information~~ |
| ~~much informations~~ | ~~much information~~ |
| ~~a software~~ | ~~some software~~ |
| ~~many information~~ | ~~much information~~ |
| ~~a hardware~~ | ~~some hardware~~ |
| ~~many data~~ | ~~much data~~ / ~~a lot of data~~ |
| ~~two softwares~~ | ~~two software packages~~ |

---

## Plurali "speciali"

Alcuni non numerabili hanno un plurale specifico:

| Singolare | Plurale |
|---|---|
| software | software **packages** / programs |
| hardware | hardware **components** |
| information | information / **pieces** of information |
| advice | **a piece** of advice |
| equipment | **a piece** of equipment |

> 💡 Per trasformare un non numerabile in numerabile usiamo *piece* o *item*: *a piece of advice*, *an item of data*.

---

## Alcuni / Molti / Poco

| Espressione | Numerabile | Non numerabile |
|---|---|---|
| **some** | some files | some information |
| **any** | any files | any information |
| **many** | **many** files ✅ | ~~many information~~ ❌ |
| **much** | ~~much files~~ ❌ | **much** information ✅ |
| **a lot of** | a lot of files | a lot of information |
| **a few** | a few files | ~~a few information~~ ❌ |
| **a little** | ~~a little files~~ ❌ | a little information ✅ |

# Present Perfect

## Collegare passato e presente

**Struttura:** **have / has + participio passato**

| Pronome | Ausiliare |
|---|---|
| I / You / We / They | **have** |
| He / She / It | **has** |

| Base | Participio passato |
|---|---|
| work | **worked** |
| write | **written** |
| delete | **deleted** |
| build | **built** |
| break | **broken** |
| run | **run** |

---

## Uso 1 — Azione passata con risultato presente

L'azione è avvenuta nel passato ma **conta ancora adesso**.

- I **have finished** my project. (adesso è pronto)
- She **has deleted** the file. (il file adesso non c'è)
- We **have lost** our connection.

## Uso 2 — Esperienza di vita

Non ci interessa *quando*.

- I **have been** to the University of Turin. (una volta nella vita)
- He **has worked** in three different countries.
- Have you ever **used** Linux?

## Uso 3 — Azioni in corso da molto tempo

- I **have worked** here since 2020.
- She **has studied** English for two years.

---

## *Since* e *For*

| Preposizione | Uso | Esempio |
|---|---|---|
| **since** | **punto di partenza** nel tempo | since **January** / since **2020** / since **I was a child** |
| **for** | **durata** | for **three years** / for **two months** |

> ⚠️ Non usarli col Simple Past: *I have worked here since ~~I was 20~~* → ✅ *since I was twenty.*

---

## Present Perfect vs Simple Past

| | Present Perfect | Simple Past |
|---|---|---|
| **quando?** | non specificato | specificato |
| **periodo** | dal 1990 a oggi | nel 1990 |
| **esempio** | I **have visited** Paris. | I **visited** Paris **in 2020**. |
| **con since/for** | ✅ | ❌ |

> 💡 Presente semplice con **already / yet / just / ever / never** → quasi sempre **Present Perfect**.

## Avverbi con il Present Perfect

| Avverbio | Significato | Posizione |
|---|---|---|
| **already** | già | I have **already** done it. |
| **just** | appena | She has **just** arrived. |
| **yet** | ancora (neg./dom.) | I haven't finished **yet**. |
| **ever** | mai (dom.) | Have you **ever** seen it? |
| **never** | mai | I have **never** used that. |
| **recently** | recentemente | He has **recently** changed it. |
| **so far** | finora | We've learned a lot **so far**. |
| **before** | prima | Have you seen it **before**? |

> 💡 **Yet** va solo in frasi **negative e interrogative**: *Have you finished yet?* ✅ · *I have finished yet.* ❌

---

## Negazione e domanda

| Affermazione | Negazione | Domanda |
|---|---|---|
| I **have done** it. | I **haven't done** it. | **Have** you **done** it? |
| He **has gone**. | He **hasn't gone**. | **Has** he **gone**? |

---

## Esercizi

| Frase | Risposta corretta |
|---|---|
| I need ___ information about the exam. | ~~some~~ / **some** |
| She ___ worked here ___ 2019. (since) | **has** ... **since** |
| How ___ time have you owned this laptop? | **long** |
| I haven't finished the report ___. | **yet** |
| How ___ hardware do you need? | **much** |
| We ___ (not) see each other ___ Monday. | **haven't seen** ... **since** |
