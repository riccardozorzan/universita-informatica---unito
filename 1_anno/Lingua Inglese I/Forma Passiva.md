# Forma Passiva (Passive Voice)

---

## Cos'è la forma passiva?

La forma passiva si usa quando **l'agente** (chi compie l'azione) è **ignoto, non importante o irrilevante**.

> **Attivo:** The developer **wrote** the code.
> Il programmatore ha scritto il codice.
>
> **Passivo:** The code **was written by** the developer.
> Il codice è stato scritto dal programmatore.

---

## Struttura

> **Soggetto + verbo TO BE (coniugato) + participio passato (+ by + agente)**

Il soggetto della forma passiva è **la persona o la cosa che subisce l'azione**, non chi la compie.

| Tempo | Struttura | Esempio |
|---|---|---|
| **Present Simple** | am / is / are + **part. passato** | The code **is written** by the developer. |
| **Past Simple** | was / were + **part. passato** | The file **was deleted**. |
| **Present Continuous** | am/is/are + **being** + part. passato | The server **is being updated**. |
| **Past Continuous** | was/were + **being** + part. passato | The file **was being copied** when I arrived. |
| **Future (will)** | will be + **part. passato** | The system **will be upgraded** next week. |
| **Present Perfect** | have/has **been** + part. passato | The bug **has been fixed**. |
| **Past Perfect** | had **been** + part. passato | The data **had been backed up**. |
| **Modal** | modal + **be** + part. passato | The file **must be deleted**. |

---

## Esempi in contesto informatico

| Tempo | Frase |
|---|---|
| Presente | The code **is reviewed** every week. |
| Passato | The server **was restarted** at midnight. |
| Futuro | The project **will be submitted** on Friday. |
| Perfect | The password **has been changed**. |
| Modale | The bug **must be fixed** today. |
| Negativo | The file **wasn't saved**. |
| Interrogativo | **Was** the email **sent**? |

---

## *By* e l'agente

*By* introduce l'agente quando è noto:

- The report **was written by** Anna.
- The system **was designed by** our team.
- The bug **was caused by** a missing import.

> 💡 **Nella forma passiva l'agente si mette quasi sempre alla fine**, con *by*.

---

## Quando si usa il passivo

1. **Agente sconosciuto**
   > My laptop **was stolen**. → Il mio portatile è stato rubato. (da chi? ignoto)

2. **Agente evidente ma non importante**
   > The exam **was written by** the professor. (sappiamo tutti chi l'ha scritto)

3. **Oggetto in evidenza, azione al centro**
   > The application **has been updated**. → Il punto è l'aggiornamento.

4. **Contesto istituzionale (formalità)**
   > It **is believed that** the bug will be fixed soon.

---

## Verbi molto usati al passivo

| Attivo | Passivo |
|---|---|
| make | **be made** |
| do | **be done** |
| write | **be written** |
| send | **be sent** |
| build | **be built** |
| install | **be installed** |
| delete | **be deleted** |
| design | **be designed** |
| create | **be created** |
| update | **be updated** |
| fix | **be fixed** |
| choose | **be chosen** |

> ⚠️ Solo i verbi che ammettono il **transitivo** possono essere passivi: *happen, occur, appear* ❌.

---

## Passivo e forma continua

Con i verbi che ammettono il continuo, il passivo usa **be + being + participio**:

> The file **is being copied** right now. (adesso)
> The server **was being replaced** when it broke.

---

## Domande al passivo

> **Was** the code **written** by Marco?
> **Has** the file **been saved**?
> **Will** the project **be completed** on time?

---

## Esercizi

| Frase | Risposta corretta |
|---|---|
| The file ___ (delete) yesterday. | **was deleted** |
| The code ___ (review) by the team. | **is reviewed** |
| The server ___ (restart) now. | **is being restarted** |
| The bug ___ (fix) already. | **has been fixed** |
| The project ___ (submit) on Friday. | **will be submitted** |
| This ___ (not / allow). | **is not allowed** |
