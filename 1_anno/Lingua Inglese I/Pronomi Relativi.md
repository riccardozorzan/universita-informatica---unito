# Pronomi Relativi

I pronomi relativi collegano due frasi e sostituiscono un nome. Si usano per evitare ripetizioni.

**Struttura:** *nome + pronome relativo + verbo*

> **The student** che **studia all'UNI**. Ho visto lo studente che studia all'UNI.

---

## Quale pronome scegliere?

| Pronome | Si usa per | Frase di esempio |
|---|---|---|
| **who / that** | **persone** | *The engineer **who** wrote the code...* |
| **which / that** | **cose e animali** | *The file **which** was corrupted...* |
| **where** | **luoghi** | *The lab **where** we work...* |
| **whose** | **possesso** | *The developer **whose** laptop crashed...* |
| **what** | **la cosa che** | *I don't know **what** he wants. |

> 💡 **Regola chiave:** *who* → solo persone. *which* → solo cose/animali. *that* → **entrambi**.

---

## Esempi contesto informatico

- **The professor** **who** teaches us programming **is** very clear. → Il professore che ci insegna programmazione è molto chiaro.
- **The folder** **which** contains the backups **is** empty. → La cartella che contiene i backup è vuota.
- **The server room** **where** the routers are kept **is** locked. → La sala server dove sono tenuti i router è chiusa a chiave.
- **The student** **whose** project failed **needs** help. → Lo studente il cui progetto è fallito ha bisogno di aiuto.

---

## Il pronome omesso

Quando il pronome relativo è **oggetto** del verbo, si può **omettere**:

> **The file (that) I deleted** was important.
> Il file che ho eliminato era importante.

Si omette **sempre** quando:

- è oggetto del verbo (*the book **I read***);
- segue una preposizione (*the person **I spoke to***).

Si **non** omette quando:

- è soggetto (*the file **that was deleted***);
- segue la preposizione (*the person **to whom** I spoke*).

---

## *Who* e *Whom*

**Who** = soggetto · **Whom** = oggetto

| Frase | Corretta |
|---|---|
| The teacher **who** helped me... | ✅ |
| The teacher **whom** I helped... | ✅ |
| The teacher **who(m)** I helped... | ✅ (whom omesso) |

> 💡 Nell'uso quotidiano **who** sostituisce quasi sempre **whom**.

---

## *Whose*

Indica possesso e funziona come aggettivo possessivo:

- **Anna's laptop** → **whose laptop** è il portatile di Anna.
- Whose code is this? → Di chi è questo codice?

---

## Virgolette e virgolette capote

Quando l'informazione è essenziale (identifica una persona specifica) si usano le **virgolette**, nientemeno:

- **The students** (tutti) **who** study here... → gli studenti che studiano qui (in generale)
- **The students** **who** study here **have passed.** → gli studenti specifici che studiano qui hanno promosso.

---

## Esercizi

| Frase | Risposta corretta |
|---|---|
| The man ___ is writing the code is my brother. | **who / that** |
| The database ___ crashed needs to be restored. | **which / that** |
| This is the room ___ the meetings are held. | **where** |
| The girl ___ laptop is broken needs help. | **whose** |
| The tutorial (___) I watched was very useful. | **that** (omesso) |
