## Il progetto SW

Applicazione Object Oriented **distribuita** con interfaccia grafica, di complessità maggiore degli esercizi. Si sviluppa in parte durante il laboratorio e in parte autonomamente.

> 💡 **Perché questo corso è il ponte verso il lavoro.** Java, thread e socket sono esattamente ciò che distingue un esercizio da un'applicazione reale. È anche la base di [[Indice - Tecnologie Web]], che usa Java per il back-end con Spring.

## Prerequisiti

- **Principi di Programmazione Orientata agli Oggetti** (2° anno) — **diretto**, Java è un linguaggio OO
- **Programmazione II** — thread e concorrenza in C
- **Reti e Sicurezza delle Reti** — i socket sono il livello di trasporto
