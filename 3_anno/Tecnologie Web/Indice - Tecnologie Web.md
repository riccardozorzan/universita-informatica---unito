## Prerequisiti

- **Basi di Dati** — il back-end persiste i dati
- **Principi di Programmazione Orientata agli Oggetti** — Java è un linguaggio OO
- **Programmazione III** — programmazione a eventi e reti, con cui si collega per l'architettura client-server

> 💡 **Perché JavaScript e TypeScript insieme.** TypeScript aggiunge a JavaScript i **tipi statici**: il codice resta JavaScript ma viene verificato prima. Serve perché il front-end è scritto a eventi e gli errori di tipo sono difficili da trovare a runtime.
